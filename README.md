# VoicedMoves
Voice-Controlled Endless Runner in Unity

## Project Overview
**VoicedMoves** is an innovative voice-controlled endless runner game developed in **Unity**, inspired by games such as *Temple Run*.  
Instead of using traditional input methods like a keyboard, controller, or touch input, the player controls the character using **voice commands** such as **“Links”** and **“Rechts”**, captured through a microphone.

The project explores **speech recognition as an alternative game input method** and examines how this impacts **gameplay responsiveness, usability, and player experience**.

---

## Goals & Objectives
- Develop a working prototype of a voice-controlled game in Unity  
- Research the reliability and usability of voice input in real-time games  
- Gain experience with:
  - Microphone input
  - Speech recognition
  - Unity gameplay mechanics
  - C# scripting

---

## Research Questions

### Main Research Question
How can speech recognition be effectively used as a control mechanism in a Unity game?

### Sub Questions
- What options does Unity offer for speech or microphone input?
- Which speech recognition technique is most suitable (built-in, plugin, or API)?
- How reliable is voice input in a real-time game?
- How does voice-controlled input affect the gameplay experience?

## Core Features
- Endless runner gameplay with automatic forward movement  
- Three-lane system (left, center, right)  
- Voice commands:
  - “Links” moves the player to the left lane  
  - “Rechts” moves the player to the right lane  
- Simple user interface:
  - Start screen
  - Score display
  - Restart option  
- Basic visual or audio feedback
